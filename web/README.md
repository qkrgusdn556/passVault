# PassVault ID Manager site

Open this file in a browser:

```text
C:\Users\qkrgu\Desktop\PassVault\web\index.html
```

## Features

- Add, edit, delete, and search website accounts.
- Generate strong passwords.
- Flag weak and reused passwords.
- Export and import JSON backups.
- Store data in this browser's local storage.

## Note

This local site does not read the encrypted C++ `vault.json` file yet. It is ready to be connected to the PassVault native messaging bridge in the next integration step.
